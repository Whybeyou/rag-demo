# AI Agent 入门笔记

## 什么是 AI Agent

AI Agent（智能体）是一个能自主感知环境、做出决策、执行行动以实现目标的系统。它区别于传统聊天机器人：聊天机器人是一问一答，Agent 是目标驱动的循环。

Agent 的核心运行范式是「感知—规划—行动」循环（Perceive-Plan-Act Loop）：
1. 感知：从用户输入、工具结果、外部数据中获取信息
2. 规划：基于目标和当前状态决定下一步做什么
3. 行动：执行动作（回复、调用工具、修改状态），再回到感知

## 多角色协作

一个 Agent 不一定是「一个模型」，而可以是「多个角色 + 一个循环」。例如 BabyAGI 把 Agent 拆成三个角色：
- 执行代理：完成具体任务，直接给结果
- 任务规划师：根据上一步结果拆出下一步子任务
- 优先级排序师：按重要性重排任务列表

三个角色底层可以共用同一个 LLM 调用，区别只在 system prompt——这就是「角色本质即 prompt」。

## 工具调用 Tool Use

LLM 本身只能生成文字，不能查天气、查数据库、发邮件。工具调用（Function Calling）让 Agent 能真正「动手」：
1. 定义工具（名称、描述、参数 schema）
2. LLM 根据用户意图决定调用哪个工具、传什么参数
3. Agent 执行工具拿到结果
4. 把结果回传给模型生成最终回答

真实任务往往需要连续调用多个工具，因此要用 tool loop（工具循环）：while 循环里反复让模型决策，直到任务完成。

## 任务爆炸问题

自主 Agent 每轮「产出大于消耗」会导致任务列表无限增长。解决手段：优先级排序（先做最重要的）、步数上限（安全阀）、任务去重。
