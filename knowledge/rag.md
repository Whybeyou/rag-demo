# RAG 检索增强生成笔记

## RAG 是什么

RAG（Retrieval-Augmented Generation，检索增强生成）把「检索」和「生成」结合起来：先从知识库检索相关资料，再把资料拼进 prompt 交给 LLM 生成答案。这样能减少幻觉、让回答有据可依。

## 离线索引阶段

1. 文档解析：把 PDF、Markdown、图片等知识源解析成文本（图片需要 OCR 或 VLM）
2. 切块：把长文档切成 chunk，并进行清洗、绑定元数据
3. 向量化：把每个 chunk 转成向量（如 BGE 中文 embedding）
4. 建立索引：BM25 稀疏索引 + 稠密向量索引（混合索引）

## 在线检索阶段

1. 查询改写：把用户口语化问题改写成更利于检索的形式
2. 多路召回：BM25 关键词召回 + 向量语义召回
3. 精排：用 Rerank 模型对召回结果重排序
4. 上下文拼装：把 top-k 结果拼成上下文交给 LLM

## 混合检索与 RRF

BM25 擅长精确关键词匹配，向量检索擅长语义相似。两者可以互补，用 RRF（Reciprocal Rank Fusion，倒数排名融合）把两路结果融合排序，通常比单路效果好。

## 评测

用 RAGAS、MRR、Hit 等指标评估检索和生成质量，量化对比不同切分策略、召回参数和重排模型。
